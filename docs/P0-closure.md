## Scope boundary

Basic manual speaker separation satisfies section 12; automated diarization and calibrated confidence were not added as extra P0 requirements. Auto Reframe, music/beat/ducking/enhancement, translation, B-roll, saved custom animation presets, discovery and batch ZIP remain P1. No P2 work was added. The independently developed YouTube/audio importer package is not included in this P0 sign-off.
