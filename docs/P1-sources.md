# P1 model and public-data sources

No API key or paid inference service is needed. Network requests occur only for requested model downloads, public stock searches/downloads and Discover refreshes. Video, audio and transcript inference stay in the browser.

- **Reframe:** Google's [MediaPipe face detector](https://developers.google.com/edge/mediapipe/solutions/vision/face_detector/web_js), using the bundled BlazeFace short-range float16 model. Runtime: `@mediapipe/tasks-vision` 0.10.32, Apache-2.0. Model source/card are linked in `public/models/README.md`. Analyze at most 250 frames per selected clip; tracking uses the nearest detected face after choosing the largest initial face, with smoothing and crop bounds. No identity recognition is performed.
- **Translation:** [Xenova/m2m100_418M](https://huggingface.co/Xenova/m2m100_418M), ONNX conversion of [Facebook M2M100 418M](https://huggingface.co/facebook/m2m100_418M) (MIT). WASM q8, about 640 MB initial weights/tokenizer download. Seven exposed language choices match the editor. Translation runs phrase by phrase in a cancellable worker. Word timings are estimated inside the original phrase; text is reviewable/editable. A changed transcript or timeline invalidates the translation and falls back visibly to the original until regenerated. This is not human-level translation or dubbing.
- **B-roll:** [Wikimedia Commons imageinfo API](https://www.mediawiki.org/wiki/API:Imageinfo). Search returns supported MP4/WebM files under 100 MB with known CC BY, CC BY-SA, CC0 or public-domain metadata. Source, creator, license and license URL are displayed and saved, and publishing drafts include credits. License terms remain those of each source; ShareAlike results are labeled. Search sends only the user's query; inserting downloads only the chosen file. The workflow rejects locked/occupied V2 ranges and preserves source speech.
- **Discover:** [official Hacker News API](https://github.com/HackerNews/API), current top-story ranking with points, publication dates, source links and fetch time. The feed covers technology/science and adjacent stories. It does not claim YouTube trend data, view predictions or a general cross-platform trend score. Topic outlines are research prompts, not generated factual reports.
- **Publishing and B-roll suggestions:** local transcript phrases/keyword heuristics, openly labeled as editable suggestions. No hidden remote LLM call or fabricated virality score.

The live stock QA selects `PIO06 Ovcarsko-Kablarska Klisura.webm` from Commons and checks its returned CC BY-SA 4.0 attribution. Its downloaded test output stays under ignored `test-results`. The moving-face QA fixture is generated locally from Google's [public MediaPipe portrait test asset](https://storage.googleapis.com/mediapipe-assets/portrait.jpg); it is ignored and is not application footage. Run `node scripts/prepare-p1-fixture.mjs` to reproduce it.

Existing FFmpeg/GPL and Noto font licensing notes in README still apply. Models and externally supplied media retain their upstream terms.
